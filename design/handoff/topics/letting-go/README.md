# Letting Go topic page handoff

Status: editorially approved direction; ready for implementation as a local
preview. Publication still requires explicit owner approval.

Target route: `/topics/letting-go/`

This folder is the source of truth for the Letting Go page update. Read the
files in this order:

1. `CLAUDE_CODE_PROMPT.md`
2. `STORYBOARD.md`
3. `ARTICLE.md`
4. `IMPLEMENTATION.md`

The files in `reference-images/` are temporary, image-generated concept
comps. They may be used as placeholders in the local mockup. They are not the
final production assets; the final inserts should use responsive live text.

## Precedence

For this page, this folder supersedes the fixed four-chapter/content rules in
`design/handoff/theme-page/README.md`. That older handoff remains a useful
reference for the established visual language, tokens, hero, topic rail,
readings grid, CTA, and footer.

The important editorial decision is that each topic gets a structure suited
to its own emotional journey. Do not force Letting Go back into the generic
`WHAT IT MEANS / WHAT IT IS NOT / A USEFUL DISTINCTION / EVERYDAY PRACTICE`
spine.

## Scope

Implement only the Letting Go topic page and any reusable styles/components
strictly required by it. Do not migrate the remaining topic taxonomy, publish,
change database rows, or remove redirects in this pass.
